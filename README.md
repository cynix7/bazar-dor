Project name : bazar-dor

Short description : It is a market price tracking web application that helps users explore daily prices of essential products in Bangladesh.

Technologies used : Next.js, React, TypeScript, Tailwind CSS, Better Auth, MongoDB, DaisyUi, React Hot Toast.

5 key features of the project:  1.Daily Market Prices 2.Category-Based Browsing 3.Price Change Tracking 4.Product Sorting 5.User Authentication
